# Личный кабинет клиента банка 

## Описание:

Это виджет, который показывает несколько последних успешных банковских операций клиента. 
В нем есть несколько функций, которые выполняют определенные задачи по работе со счетами
    и декоратор log, который будет автоматически логировать начало и конец выполнения функций, 
а также их результаты или возникшие ошибки.:

1. функция маскировки номера банковской карты и банковского счета
2. функция маскировки номера банковской карт и счета с выводом типа карты или счета
3. функция, фильтрующая спсиок словаре по статусу (исполнен/не исполнен)
4. функция, фильтрующая список словарей по дате 
5. функция, которая фильтрует транзакции по заданной валюте и возвращает транзакции, где валюта операции соответствует заданной (например, USD)
6. функция, которая принимает список словарей с транзакциями и возвращает корректные описания для каждой транзакции.
7.  функция, которая генерирует номера карт в заданном диапозоне
8. функция, которая считывает финансовые операции из файла-CSV и возвращает список словарей с транзакциями
9. функция, которая считывает  финансовые операции из файла - Excel и возвращает список словарей с транзакциями.
