# Личный кабинет клиента банка 

## Описание:

Это виджет, который показывает несколько последних успешных банковских операций клиента. 
В нем есть несколько функций, которые выполняют определенные задачи по работе со счетами:

1. Функция маскировки номера банковской карты и банковского счета
2. Функция маскировки номера банковской карт и счета с выводом типа карты или счета
3. функция, фильтрующая спсиок словаре по статусу (исполнен/не исполнен)
4. функция, фильтрующая список словарей по дате 


## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/BmargoW/project_Homework10.1
```
2. Установите зависимости:

```pip install  -r requirements.txt```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.
